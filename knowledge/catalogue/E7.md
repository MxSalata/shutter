# E7 Two sources at the same time

## Meaning

Two systems moved the same patient at the same recorded time, for example the patient administration system and the
bed manager. Every mechanical check passes, so rules alone would resend, and the resend would move the patient away
from the placement the other system made.

## Telling it apart

The other event is from another source system (MSH-3) with exactly the same event time. A strictly later event from
any source is E1 or E6.

## Cite

Both events: source system, event time, ward, and the downstream system's current state set by the other system.
