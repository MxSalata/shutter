# E7 Two sources at the same time

## Meaning

Two systems moved the same patient at about the same recorded time, for example the patient administration system and
the bed manager. Two systems' clocks don't agree to the second, so a gap this small says nothing about which came first.
Every mechanical check passes, so rules alone would resend, and the resend would move the patient away from the
placement the other system made.

## Telling it apart

The other event is from another source system (MSH-3), within the site profile's `feed.source_skew_seconds` of this one
either way (300 by default; 0 keeps the exact second). A time that can't be read counts, since nothing shows it was
outside the window. A demographic update moves nobody, so it doesn't count. A later
event from the same source, or from another one past that window, is E1 or E6.

## Cite

Both events: source system, event time, ward, and the downstream system's current state set by the other system.
