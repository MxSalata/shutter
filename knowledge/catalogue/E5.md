# E5 Failures between applied movements

## Meaning

Some movements of the encounter failed while others were delivered between them: a transfer failed, an update and a
later transfer applied, then the discharge failed. The downstream system's current state is right up to the last applied
movement; the latest failure is still due; the earlier failures are history the downstream system never recorded.

## Telling it apart

This entry is the chain's latest failure. The chain's earlier failures match E1 or E6 on their own, which is why the
board, not the policy, settles the chain.

## Cite

The chain in event order with each item's outcome, the applied movements between them, and the site's history policy.
