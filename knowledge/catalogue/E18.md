# E18 Held until its schema was imported

## Meaning

The site answered yes to "prevent failures" (question 13): a message whose HL7 schema category is not loaded in the
namespace that read it is held as a case, and nothing is sent, because IRIS would read its fields by position and the
receiver could get values from the wrong place. Once the schema is imported and the inbound item's category set, the
index's check releases the case: fresh evidence reads the message against the schema, and the movement, never sent, is
still the patient's latest. It goes out as any movement that never arrived does.

## Telling it apart

The failure is `unreadable` (reason `schema_unknown`), not a refusal or an unavailable receiver: the receiver never saw
the message. Until the schema is imported the gate blocks the case with `SCHEMA_UNKNOWN`, and this entry is not reached.
A later movement of the encounter applied meanwhile (from another source) is not nothing later: the case is E1. Several
held movements of one encounter form a chain, which this entry does not cover, so a person decides their order.

## Cite

The hold (the category and the namespace that lacked it), the import that released it, the receipt lookup (404), the
downstream system's current version and state, and the timeline with no later event.
