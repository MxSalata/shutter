# E12 A message that can't become a downstream operation

## Meaning

The feed received an ADT message it could not map to a downstream operation: a field the operation needs (the visit
number, the event time, the patient identifier) is missing or malformed, or the profile maps no operation for its
event. Shutter opens a case for it so the failure isn't lost, with the message's fields and a key of its own, but
there is no operation behind the case: nothing can be resent, and the gate's conformance check blocks any plan that
tries (UNMAPPABLE). The case goes to a person with the reason named.

## Telling it apart

Every other entry starts from an operation the receiver failed, refused or may have applied. Here the receiver was
never asked: the message stopped at the mapping. A message that maps but fails schema validation is not this entry,
since it has an operation; the board reads its validation evidence.

## Cite

The message and the mapping's error (the failure text), the schema validation, and the absence of an operation key
derived from the message's fields.
